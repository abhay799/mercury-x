# Phase 0 Task 6: Runtime Event and State Transition Baseline

Implement immutable, evidence-only runtime event and state-transition contracts.

## Scope

- Runtime event types, state transitions, and event evidence.
- Fail-closed validation for identifiers, attempts, required target states, recovery actions, failure evidence, checkpoints, and consistent event identity.

## Non-goals

No runtime execution, retry loops, scheduler or worker behavior, checkpoint persistence, telemetry exporters, or later Phase 0 work.
