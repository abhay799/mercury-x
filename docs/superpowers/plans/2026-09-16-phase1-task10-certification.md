# Phase 1 Task 10: Integration Certification

Certify the Cognitive Gateway with immutable, machine-readable, fail-closed gate evidence.

## Scope

- Require complete passing evidence for Phase 1 Tasks 1 through 9, identity consistency, boundary compliance, the full regression suite, and documentation.
- Reject missing, failed, blank, duplicate, or incomplete gate evidence.
- Fail certification for model selection, hardware selection, Workload Intelligence, execution graph or scheduler, or workload execution boundary violations.
- Evaluate `configs/certification/phase1.json` as the Phase 1 certification record.

## Non-goals

No Phase 2 Workload Intelligence, model or hardware selection, execution graphs, scheduling, or workload execution.
