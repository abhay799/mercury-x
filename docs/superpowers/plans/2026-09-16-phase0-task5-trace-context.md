# Phase 0 Task 5: Execution Identity and Trace Context Baseline

Implement immutable, evidence-only execution identity and trace-context contracts.

## Scope

- Execution identity, trace context, trace relation, and trace link records.
- Fail-closed validation for required identifiers, non-negative attempts, self-links, secret-bearing extras, and immutable evidence.

## Non-goals

No OpenTelemetry integration, logging, telemetry storage, exporters, distributed propagation, scheduler/runtime behavior, or later-phase work.
