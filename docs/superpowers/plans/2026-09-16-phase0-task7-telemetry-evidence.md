# Phase 0 Task 7: Telemetry Evidence Baseline

Implement immutable, evidence-only telemetry contracts.

## Scope

- Telemetry evidence kinds, measurement sources, execution measurements, and evidence records.
- Fail-closed validation for required identities, metric names and units, finite values, unique metrics, immutable collections, and explicit measurement provenance.

## Non-goals

No telemetry storage, OpenTelemetry, Prometheus, exporters, scheduler feedback, SLO optimization, learning, or later Phase 0 work.
